# ALX Low-Level Programming

A collection of C programming exercises from the ALX Software Engineering curriculum, focused on the foundations of programming and systems-level development.

## Topics covered

The repository is organized into numbered assignments covering areas such as:

- C compilation and the basic program structure
- Variables, conditionals, and loops
- Functions and nested loops
- Debugging
- Pointers, arrays, and strings
- Memory management and additional low-level concepts as the coursework progresses

## Concepts practised

- Writing and compiling C programs
- Understanding pointers and memory
- Breaking problems into reusable functions
- Working with arrays and strings
- Debugging and following coding standards

## Working with the exercises

Each numbered directory contains a separate set of tasks. Compile individual programs with the compiler flags specified by the relevant assignment. A common starting point is:

```bash
gcc -Wall -Werror -Wextra -pedantic source.c -o program
```
